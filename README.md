# 消息合并转发 (astrbot_plugin_packsend)

AstrBot 插件，根据 Bot 单次发送消息长度自动将长消息转为 QQ 合并转发消息，支持按群独立设置上限。检测到用户发送 `/` 指令后，自动拦截后续输出并在指定时长后合并为一条聊天记录转发。

## 功能特性

- **按群独立设置上限**：每个群聊可单独配置 Bot 单次发送消息的文本长度上限
- **自动合并转发**：当消息文本长度达到上限时，自动转为 QQ 合并转发消息
- **指令拦截合并**：检测到用户发送 `/` 指令后，自动拦截该群后续 Bot 输出，在指定时长后合并为一条聊天记录转发消息，避免刷屏打扰群成员
- **LLM 辅助判断**（可选）：启用后使用启发式规则判断是否需要延长拦截时间，避免频繁发送多条合并转发
- **高优先级执行**：插件优先级设为 100，确保消息拦截钩子在其他插件之前执行
- **管理员指令**：支持在群聊中使用 `/pack rate` 指令快速设置上限
- **仅 aiocqhttp 平台生效**：仅在 QQ 群聊场景下工作，不影响其他平台

## 安装

将插件文件夹 `astrbot_plugin_packsend` 放入 AstrBot 的 `data/plugins` 目录，重启 AstrBot 即可。

## 配置说明

在 AstrBot 插件管理后台可配置以下参数：

### 消息长度上限

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `default_limit` | int | -1 | 所有群聊的默认上限（Bot 单次发送消息的 Plain 文本长度） |
| `group_limits` | dict | {} | 为特定群聊设置独立上限，格式：`{"群号": 上限值}` |

### 指令拦截合并

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `intercept_enabled` | bool | true | 启用 `/` 指令消息拦截合并 |
| `intercept_duration` | int | 5 | 拦截时长（秒），建议 3-10 秒 |
| `use_llm_intercept` | bool | false | LLM 辅助判断拦截时长（需 Bot 已配置 LLM） |

### 上限值含义

| 值 | 含义 |
|----|------|
| -1 | 不启用此功能，消息正常发送 |
| 0 | 该群所有消息均以合并转发形式发送 |
| >0 | Bot 单次发送消息的文本长度达到该值时转为合并转发 |

### 配置示例

```json
{
    "default_limit": 500,
    "group_limits": {
        "123456789": 100,
        "987654321": 0,
        "111222333": -1
    },
    "intercept_enabled": true,
    "intercept_duration": 5,
    "use_llm_intercept": false
}
```

## 管理员指令

在群聊中发送以下指令（仅管理员可用）：

```
/pack rate <数字>
```

**示例：**

```
/pack rate 100    # 设置当前群上限为 100 字符
/pack rate 0      # 该群所有消息均以合并转发发送
/pack rate -1     # 关闭该群的消息合并转发功能
```

## 工作流程

### 长度上限模式

1. Bot 准备向群聊发送消息
2. 插件检查该群的发送上限配置
3. 若上限为 -1（不启用），消息正常发送
4. 若上限为 0，始终使用合并转发
5. 若上限 > 0 且消息文本长度达到上限，自动转为合并转发消息
6. 若上限 > 0 但消息文本长度未达到上限，消息正常发送

### 指令拦截模式

1. 用户在群聊中发送 `/` 开头的指令（如 `/pack rate`、`/help` 等）
2. 插件检测到指令，启动拦截定时器（默认 5 秒）
3. 拦截期内 Bot 的所有输出被暂存，不直接发送到群聊
4. 定时器到期后，所有暂存消息合并为一条聊天记录转发消息发送
5. 若启用 LLM 辅助判断，会在到期时分析消息是否完整，不完整则自动延长拦截

## 兼容性

- 平台：aiocqhttp（QQ）
- AstrBot 版本：>=4.16, <5
